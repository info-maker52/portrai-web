# PortrAI website

The new portrai.ee — Next.js 16, Tailwind CSS v4, Vercel.

> **Direction B — Studio Lab.** Cursor-reveal hero, editorial frame, dark + purple. See `CLAUDE.md` for the full project context and conventions.

## Quick start

```bash
npm install
cp .env.example .env.local   # fill in real values
npm run dev                  # http://localhost:3000
```

Pages:
- `http://localhost:3000` — Estonian home
- `http://localhost:3000/en` — English home
- `http://localhost:3000/design` — design tokens preview (Stage 2 sign-off)
- `http://localhost:3000/en/design`

## Stack

- **Next.js 16** (App Router, React 19, Turbopack)
- **Tailwind CSS v4** with `@theme` design tokens
- **next-intl** for i18n (ET default at `/`, EN at `/en/...`)
- **Geist Sans + Geist Mono** via `next/font/google`
- **motion** (Framer Motion v12), **GSAP**, **three / @react-three/fiber** for the cursor-reveal hero (Phase 5)
- **next-mdx-remote + gray-matter** for case studies and blog posts
- **nodemailer** for the booking form (Gmail Workspace SMTP)

## Structure

```
src/
├── app/
│   ├── layout.tsx           — root <html> + Geist fonts
│   ├── globals.css          — Tailwind v4 + @theme tokens
│   └── [locale]/
│       ├── layout.tsx       — NextIntlClientProvider + metadata
│       ├── page.tsx         — home (placeholder until Phase 3)
│       └── design/page.tsx  — token preview
├── i18n/
│   ├── routing.ts           — locale config
│   ├── navigation.ts        — locale-aware Link / useRouter
│   └── request.ts           — server-side i18n config
├── lib/
│   ├── cn.ts                — Tailwind class merger
│   └── seo.ts               — metadata + schema helpers
├── messages/                — locale strings
└── middleware.ts            — next-intl routing
```

## Useful scripts

```bash
npm run dev      # development with Turbopack

npm run start    # serve production build locally
npm run lint     # ESLint
```
